1. System Overview

Platform Purpose: MPS FSG is a production-grade serverless platform for facilities services tracking with mobile offline support, real-time analytics, and automated reporting.

Technology Stack

Backend (AWS)

  • AWS SAM (Serverless)
  • Python 3.12 on ARM64
  • PostgreSQL 16.14 (RDS)
  • AWS Cognito (Auth)
  • API Gateway (HTTP API)
  • S3, EventBridge, CloudWatch

Frontend (Next.js)

  • Next.js 16 (App Router)
  • React 19.2.3
  • TypeScript 5.9.2
  • Tailwind CSS v4
  • TanStack Query
  • AWS Amplify (Cognito)

7. Recommendations

High Priority

1. Implement Missing Database Tables

Backend needs to implement:

  • customers table with full CRUD operations
  • lines table (production lines within sites)
  • contracts table (separate from sites)
  • task_categories table for task organization

2. Standardize Field Naming Convention

Choose one convention and apply consistently:

  • Option A: Backend returns snake_case, API layer converts to camelCase for frontend
  • Option B: Update database schema to use camelCase (not recommended)
  • Recommended: Option A with automatic serialization middleware

Medium Priority

3. Align Status Enums

Synchronize status values between frontend and backend:

  • Add in_progress, missed, flagged to backend scheduled_occurrences status
  • Or remove these from frontend if not needed
  • Document which statuses are computed vs stored

4. Add Site Branding Support

Backend should support:

  • qr_prefix field on sites table (4-char prefix for QR codes)
  • logo_url field or separate site_branding table
  • S3 bucket for logo uploads

Low Priority / Future Enhancements

5. Expose Audit Log in Frontend

Backend has comprehensive audit logging - consider exposing in admin UI:

  • Add GET /audit-log endpoint
  • Create Admin Audit Log page
  • Filter by entity type, action, date range, user

6. Integrate Shift Check-ins

Backend has shift check-in functionality - integrate in frontend scheduling:

  • Add check-in widget to scheduling page
  • Show active shift personnel
  • Track attendance metrics

7. Consider AI Features

Backend has AIService (optional) - evaluate if needed:

  • Scheduling suggestions based on historical patterns
  • Natural language query for reports
  • Requires NAT Gateway ($32/month additional cost)
